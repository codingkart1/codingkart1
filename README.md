# Codingkart

**Shopify, Shopify Plus, and WooCommerce development for growing DTC brands — custom builds, subscription systems, migrations, and integrations.**

We're an ecommerce development agency working with Shopify, Shopify Plus, and WooCommerce since 2013. From full store builds and replatforming to the work where off-the-shelf tools stop: subscription apps like Recharge, Appstle, Bold, or Skio handle the standard 80% well — we engineer the 20% that's unique to each business. Custom billing logic, subscriber portals, checkout extensions, and the integrations that keep an ERP, 3PL, and CRM agreeing with each other.

## What we build

- **Full Shopify & WooCommerce builds** — custom themes, stores built from scratch, and performance-focused storefronts
- **Migrations & replatforming** — platform-to-platform and app-to-custom moves, with the risky parts (like payment-token portability) scoped before the project starts
- **Shopify Plus engineering** — Checkout UI Extensions, Shopify Functions for in-checkout pricing and validation, headless storefronts on Hydrogen
- **Custom subscription systems** — attribute-driven pricing (pet weight, household size, usage), one-to-many subscriber models, custom dunning flows, and full builds on Shopify's native Selling Plan / Subscription Contract APIs
- **Custom Shopify apps** — embedded admin tooling and merchant-facing apps when the App Store runs out of answers
- **API & systems integration** — webhook-driven sync between store/subscription state and ERP / 3PL / CRM systems
